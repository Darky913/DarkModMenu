DARK MOD MENU - Android Studio project

This is a standalone Android settings/demo app. It does not connect to, inject into,
modify, or provide cheats for Free Fire.

Build:
1. Install Android Studio.
2. Open the DarkModMenu folder.
3. Let Android Studio sync the Gradle project.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location (usually app/build/outputs/apk/debug/app-debug.apk).

The app stores its toggle and slider settings locally on the device.
